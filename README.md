# 🍎 Food Freshness AI Backend

An AI-powered backend that uses computer vision and deep learning to analyze food images and classify freshness as **Fresh or Rotten**, based on the trained model's supported classes.

## ✨ Features

- AI-based food freshness classification.
- Image preprocessing and model inference.
- REST API built with FastAPI.
- PyTorch and ONNX Runtime support.
- Backend integration for web and mobile applications.
- Docker and cloud deployment support.

## 🛠️ Tech Stack

- **Language:** Python
- **Backend:** FastAPI, Uvicorn
- **AI/ML:** PyTorch, Torchvision, ONNX Runtime
- **Image Processing:** Pillow, NumPy, OpenCV
- **Deployment:** Docker, Vercel

## 🔄 Workflow

1. Upload a food image.
2. Preprocess the image.
3. Run AI model inference.
4. Return the freshness prediction through the API.
