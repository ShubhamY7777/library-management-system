# 📚 Library Management System

A web-based library management application built with **Python, Flask, and MySQL**, featuring book management, inventory tracking, and OCR-based shelf detection.

## ✨ Features
- Book management and search functionality
- Bulk book import using Excel
- OCR-based book identification from shelf images
- Image processing using OpenCV and EasyOCR
- Fuzzy text matching for improved book recognition
- MySQL database integration

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** MySQL
- **Computer Vision:** OpenCV
- **OCR:** EasyOCR
- **Text Matching:** RapidFuzz
- **Data Processing:** Pandas

```text
├── static/                # CSS, JavaScript, and assets

```

## 🔄 Workflow
1. Import and manage book records.
2. Search for books by title.
3. Upload shelf images for scanning.
4. Extract text using OCR.
5. Match detected text against the book database.
